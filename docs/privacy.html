쇼츠블럭 개인정보 처리방침

쇼츠블럭(Shorts Blocker)은 사용자의 어떤 개인정보도 수집하거나 외부로 전송하지 않습니다.

저장되는 데이터

  • 오늘 쇼츠 시청 시간, 하루 한도, Off 상태만 chrome.storage.local(브라우저 로컬)에 저장됩니다.
  • 이 데이터는 사용자의 기기를 벗어나지 않습니다.

수집하지 않는 것

  • 개인 식별 정보(이름, 이메일, 계정 등)
  • 시청 기록, 검색어, 방문 URL
  • 광고 식별자 / 추적 쿠키

외부 전송 / 제3자 제공

없음. 분석 도구, 광고 SDK, 외부 서버 통신을 일절 사용하지 않습니다.
