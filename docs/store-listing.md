## 2. 스크린샷 계획 (1280×800 PNG, 최소 1장 / 권장 5장)

실제 동작 화면을 캡처하면 됩니다. 캡처 후 1280×800으로 맞추세요 (남는 여백은 #161616 배경으로 채우면 통일감 좋음).

1. **팝업** — 툴바 아이콘 클릭한 상태 (오늘 사용량 + 한도 슬라이더 + Off 버튼)
2. **차단 페이지** — "쇼츠는 그만 🛑" 화면
3. **30초 대기 카드** — "잠깐만요 ☕" + 오늘 시청 시간 + 카운트다운
4. **홈 비교** — 쇼츠 숨겨진 유튜브 홈 (Off로 다시 보이는 것과 Before/After 합쳐도 좋음)
5. **Off 메뉴** — 15분 / 1시간 / 무제한 펼친 상태

> 캡처 방법: Chrome에서 해당 화면 띄우고 `Win + Shift + S`(영역 캡처) 또는 개발자도구 디바이스 툴바로 1280×800 설정 후 캡처.

## 3. 제출 절차 (순서대로)

### A. 개인정보 처리방침 URL 만들기 (GitHub Pages)
1. GitHub에 `shorts-blocker` 레포 만들고 코드 push
2. 레포 **Settings → Pages → Source: `main` 브랜치 `/ (root)`** 선택 → Save
3. 몇 분 뒤 URL 생성: `https://dhkd3213.github.io/shorts-blocker/docs/privacy.html`
   - 이 URL을 웹스토어 "개인정보 처리방침" 칸에 입력

### B. 웹스토어 개발자 등록
1. https://chrome.google.com/webstore/devconsole 접속 (구글 계정 로그인)
2. **일회성 등록비 $5 결제**

### C. 확장 업로드
1. "새 항목" → `shorts-blocker-v0.2.zip` 업로드
   (zip 위치: `C:\Users\user\Documents\claudecode\shorts-blocker\shorts-blocker-v0.2.zip`)
2. 위 1번의 등록 정보(이름/설명) 붙여넣기
3. 2번의 스크린샷 업로드
4. 카테고리: 생산성 / 언어: 한국어
5. 개인정보 처리방침 URL 입력 (A에서 만든 것)
6. "데이터 사용" 항목: **"사용자 데이터를 수집하지 않음"** 체크
7. 제출 → 심사 (보통 1~3일)

## 4. 권한 사용 사유 (심사 시 물으면 답변용)

- `storage`: 시청 시간·설정을 로컬에 저장
- `alarms`: 매일 자정 사용량 초기화, Off 시간제 자동 해제
- `tabs`: 한도 초과 시 열린 쇼츠 탭에 차단 신호 전송
- `host_permissions (youtube.com)`: 쇼츠 페이지 시청 시간 측정 + UI 숨김

모두 핵심 기능에 필수이며 최소한으로만 요청합니다.
